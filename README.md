# Titanic Data Cleaning Project

## Project Overview

This project focuses on cleaning and preprocessing the Titanic dataset using Python. The goal is to handle missing data, encode categorical variables, and visualize passenger information for further analysis.

## Objectives

- Load the Titanic dataset using Pandas
- Explore the dataset using `info()` and `describe()`
- Handle missing values using mean/median imputation
- Encode categorical variables
- Analyze passenger survival
- Visualize age distribution by survival

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset

The project uses the Titanic Dataset, which contains passenger information such as:

- Passenger Class
- Sex
- Age
- Fare
- Embarked
- Survival

## Project Workflow

1. Load the dataset
2. Explore the dataset
3. Handle missing values
4. Encode categorical variables
5. Perform survival analysis
6. Visualize age distribution
7. Save the cleaned dataset
